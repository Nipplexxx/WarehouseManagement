# Складское хозяйство

Простая десктопная программа для автоматизации учёта товаров на складе.

---

## Возможности программы

- Авторизация и регистрация пользователей (две роли: **Администратор** и **Кладовщик**)
- Управление товарами (добавление, редактирование, удаление, поиск)
- Приход товаров на склад
- Расход товаров со склада (с проверкой остатка)
- Просмотр текущих остатков на складе
- История всех операций (приходы и расходы)

## Технологии

- **Язык:** Java
- **Интерфейс:** Java Swing
- **Хранение данных:** текстовые файлы (`.txt` в формате CSV)
- **Среда разработки:** IntelliJ IDEA

## Как запустить проект

1. Скачайте или клонируйте репозиторий
2. Откройте проект в **IntelliJ IDEA**
3. Запустите главный класс `Main.java`
